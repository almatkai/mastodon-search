# Behavior and explicit limits

The reference is the complete own `src/search.tsx`, all model/view files, package/actual lock, tests, documentation and assets at `dd73024af23ed7d716421592aac26c323500206d`. The locked hook is `@raycast/utils` **2.3.0**, not the manifest's minimum 2.2.2. The finite VM oracle executes those complete source files and the authentic registry bundle with network, host, filesystem, storage and clock producers replaced before evaluation. It does not claim universal Raycast GUI equivalence.

## Preserved behavior

- One command, default People, People/Hashtags dropdown in source order, required unmodified instance preference. `storeValue: true` is transported; the separate generic host proposal restores/saves the selected dropdown value under an extension/command key. No query or response is persisted.
- The raw URL is exactly `https://${instance}/api/v2/search?type=${kind}&q=${query}`, then WHATWG parsing. It is not form encoding or `encodeURIComponent`. `&` can introduce another parameter, `+` stays `+`, `#` starts a fragment, `%` is retained, spaces become `%20`, and tabs/newlines are removed by URL parsing. Fragments are not sent. Instance ports, paths, query/fragment quirks are not normalized into another target. Credentials in a URL are rejected, as by Fetch's Request constructor.
- Execute only if JS UTF-16 query length is greater than zero. Whitespace is not trimmed. The original query remains displayed even when URL parsing changes the wire target.
- Both returned arrays are rendered: People first, then Hashtags. No ranking, local filtering, deduplication, kind filtering, or array merging. Duplicate account IDs and hashtag names retain separate rows via positional native IDs. Raw string and numeric account IDs are accepted; ordinary Mastodon string IDs are not parsed as `u64`.
- Account title is `display_name`, including an empty title. A federated `acct` gets one leading `@`; a local `acct` gets `@acct@<exact instance>`. Bot accessory precedes follower count, with source tooltips/icons. Follower formatting uses JS Number-to-string semantics, including `1e+21` and negative zero. Avatar URL is source data and keeps the rounded-rectangle mask.
- Account actions: **Visit Profile**, **Copy Profile URL** (`cmd-shift-c`), **Copy Handle** (`cmd-shift-opt-c`). Hashtag action: **Visit Hashtag**. URLs/text are frozen from the displayed row. No hide, paste, follow, account, auth, or settings effects are added.
- Previous data stays during a refresh and a failed refresh. An exact raw-URL cache hit is selected for A/B/A before revalidation; a miss retains the preceding payload. Clearing the query stops work while retaining the prior payload, matching the locked hook. Cache keys include the complete raw instance/kind/query URL; there is no cross-key merging.

## Deliberate necessary adaptations

The original custom `onError` produces an Error toast with no retry action, and logs the error. The port displays a plain error message, logs no query/account/URL/body, and exposes **Retry Search** manually. The source default MIME parser recognizes JSON subtypes/suffixes with its RFC 6838 grammar; other MIME becomes text and subsequently fails the source model's array mapping. The port uses that same JSON media-type predicate and makes non-JSON/malformed JSON/arrays/types explicit errors before replacing valid rows. Numeric HTTP status replaces untrusted, potentially absent status text. Invalid API types that could crash a React render become visible errors. There is no automatic request, effect or manual-retry replay.

The original hook uses persistent Raycast Cache. This port keeps a private in-memory exact-key LRU: four entries and 4 MiB of cached compact payload per session. Old cache entries are evicted, never partially truncated or merged. Cache is discarded at session disposal/process exit. Cross-command cached response restoration and legacy Raycast cache migration are not claimed. This privacy/bounding adaptation is separate from the small host-owned persisted dropdown selection.

HTTP is a direct public GET to the selected instance. HTTPS trust uses the dependency's WebPKI roots, ignores proxy environment settings, and has no QA endpoint, trust flag, environment override, fixture handler or stored credentials in the product. Redirects are limited to five on the same HTTPS origin; credential-bearing/cross-origin/downgrade redirects are rejected explicitly. These limits are stricter than browser Fetch's cross-origin redirect behavior. Connect is bounded at 5 s, stalled reads at 5 s, and the entire response at 15 s. There are no adapter retry loops. OS DNS resolution is provided by the HTTP/runtime libraries; immediate cancellation of an already-running OS resolver is not asserted. Socket/body-read cancellation is tested.

Limits reject rather than truncate: query 4,096 UTF-16 units, instance 2,048 units, each mapped string 16 KiB, body 2 MiB, combined rows 512, JSON nesting 64, JSON work 100,000 nodes. Invalid drafts revoke work and old effects **before** value validation. An invalid draft cannot leave an earlier response active. The session's one active HTTP generation and one pending effect use scope-owned tasks and cancellation watches. HTTP work belongs to the original open-session scope: a stale search RPC cannot cancel newer HTTP work through the pinned SDK's reader-ordered RPC cancellation. Valid newer input revokes it through the owned revision watch; cancelled opens, disposal, EOF and shutdown stop the scope. The SDK caps sessions at 128, handlers at 120 plus eight control slots, output queue at 256, reverse RPC at 128, tasks at 64 per scope, and frames at 16 MiB LF JSONL. Saturation is an explicit busy/full error, not a silent reset. These library constants are preserved in the immutable fixtures; not every scheduler saturation is exhaustively explored.

Session/query ownership and monotonically increasing model snapshots live outside the SDK's staged JSON `Value`. The client owns an independent input revision. The host proposal sends a draft-only revocation at input time and promotes that same input after its existing 200 ms debounce. Native model revisions never overwrite client input revisions. Typed client text, including an invalid draft, stays visible; an older debounce cannot borrow the revision of newer typed text. A/B/A and rapid dropdown changes, invalid/valid transitions, crossed responses, old refreshes, effect acknowledgements and disposed sessions are fenced. The dropdown is a stable session-owned value-change control with client-revision fencing; effect and retry tokens are consumable and freshly minted for deliberate subsequent actions.

Effect consumption and uncertainty checkpoints also live outside staged JSON. A token is consumed before spawning/awaiting; duplicate, stale and foreign tokens are inert `unchanged`. Concurrent duplicates require one effect and one view/one unchanged reply; no particular scheduled task must win. `clipboard.write` and `shell.open` require closed `{ok:true,message?:string}` acknowledgements. Failures, malformed acknowledgements, timeouts (20 s) or dropped work expose an explicitly uncertain **Retry Last Action** with the exact frozen payload. Refresh emits no effects. No exactly-once or crash-durability guarantee is made.

## Host and acceptance gaps

`integration/host-prerequisites.patch` is **unapplied**, against host `ea100cee3f69711de12485ba061950c5fc65258f`. It adds generic input/model ownership, visible loading/empty states, controlled/persisted dropdowns, source shortcuts and action reachability, avatar masks, accessory tooltips/icons, and safe remote raster loading. Tests execute actual original/patched component functions in a deterministic hook VM, plus a typed-seam compiler check. They are not a DOM screenshot, a full host build, or installed-host acceptance.

Remote image adaptation: HTTPS only, no credentials/cookies/referrer/persistent cache/redirects, 5 s timeout, 2 MiB body, validated PNG/JPEG/GIF/WebP dimensions before an object URL, 4,096 per edge and 4,194,304 pixels. AVIF/SVG, HTTP avatars, unusual WebP headers, oversized or redirected avatars yield an empty avatar slot. Local/package image paths use existing host handling. Browser codec/frame-cache internals are not a process memory guarantee. The unchanged extension icon is not remotely fetched or converted by this port.

The production executable genuinely rejects the private fixture CA. Successful owned TLS tests use a **different QA executable** built from the same adapter with an explicitly supplied fixture CA. That helper, its arguments and its CA are outside the package. Production successful live-service requests were deliberately not performed. Extracted genuine production tests cover all applicable no-network operations, TLS rejection, framing and lifecycle; successful data/action cases belong to the trusted helper. Native installed macOS acceptance is not run. Windows GNU check/Clippy attempts stop in `ring` because MinGW GCC is unavailable; GNU is not the intended MSVC artifact. Windows MSVC compilation, runtime and UI acceptance are not run. Stable release compilation succeeds with an existing `rust-objcopy`/missing-LLVM strip warning, recorded in `qa/evidence/fresh-release.txt`; no toolchain was repaired or installed.
